# 🆕 POLSKA WATAHA V0.2 — NOWE FUNKCJE

## 1. Wygląd: nowoczesny 3D w stylu OLX
- **Hero na pulpicie**: fotorealistyczny **Orzeł w koronie** (wygenerowany, ~90 KB) z gradientową nakładką
  biało-czerwoną, tytuł „CZARNY WILK CZUWA" + wyszukiwarka OLX.
- **Menu wysuwane z lewej** (☰): tło **wataha czarnych wilków** (fotorealistyczna, ~100 KB),
  zamykane **✕** (rogu), profil użytkownika, 15 pozycji + wylogowanie.
- **GradientButton** — 3D „wypukłe" przyciski: skala 0.95 + głęboki cień + **wibracja (haptics)** na dotyk.
- **GlassCard** — glassmorphism: półprzezroczysta biel, gradientowa ramka bordowa, cień 12 dp.
- **EmojiTile** — płytki z emoji na gradiencie kategorii; **NeoChip** — chipy 3D z animacją.
- Ogłoszenia na stronie głównej (feed OLX) z akcjami: 💬 Napisz / 🔁 Wymiana / 🤝 Pomogę.

## 2. 🧠 Asystent WILK (glosowo-tekstowy, offline)
| Element | Realizacja |
|---------|-----------|
| Rozpoznawanie mowy | `SpeechRecognizer` + Intent RECOGNIZE_SPEECH (pl-PL) — systemowy, offline po pobraniu pakietu głosu |
| Odpowiedź głosowa | `AssistantVoice` — `TextToSpeech` (pl-PL), przycisk GŁOS: ON/OFF |
| Wiedza | `SurvivalData.KB` — ~30 wpisów Q&A (woda, ogień, RKO, powódź, burza, plecak 72h, SOS, mesh…) |
| Dopasowanie | `AssistantEngine` — normalizacja polskich znaków + scoring słów kluczowych |
| Kryzys | słowa alarmowe (`SOS`, `ratunku`, `pomocy!`) → odpowiedź kryzysowa + przycisk „AKTYWUJ TRYB KRYZYSOWY" |
| Filozofia | **deterministyczny, lokalny — bez modelu samouczącego się**; przy braku trafienia uczciwy fallback |
| Wizualizacja | fotorealistyczny czarny wilk + czat jak w komunikatorze + szybkie pytania |

Testy: `AssistantEngineTest` (5/5) — woda→Woda, SOS→crisis, 72h→checklista, fallback, ignorowanie polskich znaków.

## 3. 🏕️ Poradnik survivalowy
- 12 sekcji (🎒 checklista 72h, 💧 woda, 🔥 ogień, 🏠 schronienie, 🩹 medycyna, 🧭 orientacja,
  📡 łączność/SOS, 🌡️ pogoda, 🔌 energia, 🧠 psychologia, 🐕 zwierzęta, 📄 dokumenty).
- Akordeon z animacją, wyszukiwarka po tytule/tagach (ignoruje polskie znaki),
  **checklista plecaka 72h** z odhaczaniem i licznikiem „GOTOWY: n/8".
- 100% offline (dane w kodzie APK).

## 4. 💡 „Masz pomysł? To napisz!" (→ Administracja)
- Tematy: Pomysł / Błąd / Nadużycie / Współpraca / Inne → treść → lokalnie (Room, tabela `feedback`)
- → kolejka synchronizacji → **POST `/api/feedback`** → panel web (zakładka „💡 Pomysły").
- Lista „Moje zgłoszenia" ze statusem ⏳/✅; powiadomienie potwierdzenia.
- Backend: kolekcja `feedback` (+ kompatybilność starych baz przez `Object.assign`).
